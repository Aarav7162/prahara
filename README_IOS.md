# Prahara • iOS Installation Guide (Without App Store)

This guide explains how to install **Prahara (A Jain Daily Panchakkhan & Tithi Tracker)** directly onto your iPhone **without needing the Apple App Store**.

---

## 🚀 Method 1: Instant Standalone iOS Installation (Recommended - No Mac / No App Store Needed)

Apple iOS (iPhone) natively supports installing Progressive Web Apps directly onto your Home Screen. It runs full-screen without Safari browser bars, works **100% offline**, has its own app icon on your Home Screen and App Library, accesses GPS for solar math, and plays trilingual sutra recitations!

### Option A: Local Wi-Fi Installation (Right Now from your PC)
Your computer's current local Wi-Fi IP address is: **`192.168.0.101`**

1. On this computer, start the local server:
   ```bash
   cd "ios-app"
   npm run dev -- --host
   ```
2. Make sure your iPhone is connected to the same Wi-Fi network.
3. Open **Safari** on your iPhone and visit:
   ```text
   http://192.168.0.101:5173
   ```
4. In Safari, tap the **Share** button (the square with an arrow pointing up at the bottom of the screen).
5. Scroll down the share sheet and tap **"Add to Home Screen"** (`+` icon).
6. Tap **"Add"** in the top right corner.
7. **Done!** The Prahara app icon is now on your iPhone Home Screen. Tap it to launch full-screen.

---

### Option B: Deploy Free to GitHub Pages (Access Anywhere)
We have included a ready-to-run GitHub Actions workflow in `.github/workflows/deploy-pwa.yml`.

1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "Add iOS application"
   git push origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Source**, choose **GitHub Actions**
3. The workflow will automatically deploy your app to:
   ```text
   https://aarav7162.github.io/prahara/
   ```
4. Open that URL on your iPhone in Safari, tap **Share** > **"Add to Home Screen"**.

## 📱 Method 2: Sideloading Native IPA via Windows PC (AltStore / Sideloadly)

If you prefer installing a native compiled `.ipa` binary package onto your iPhone using a Windows PC:

### Step 1: Download the IPA
You can download the prebuilt unsigned `.ipa` generated by GitHub Actions:
- Go to the **Actions** tab in your GitHub repository.
- Run the **Build iOS Xcode App** workflow.
- Download the `Prahara-iOS-App` artifact (`.ipa` file).

### Step 2: Sideload using Sideloadly on Windows
1. Download [Sideloadly](https://sideloadly.io/) on your Windows PC.
2. Connect your iPhone to your PC using a Lightning / USB-C cable.
3. Open Sideloadly:
   - Drag and drop `Prahara-unsigned.ipa` into Sideloadly.
   - Enter your personal Apple ID (used only to sign the binary for your device).
   - Click **Start**.
4. Once completed, unlock your iPhone:
   - Go to **Settings** > **General** > **VPN & Device Management**.
   - Tap your Apple ID under Developer App and tap **"Trust"**.
5. Launch **Prahara** directly on your iPhone!

## 💻 Method 3: Compile via Xcode on macOS

If you or a friend have a Mac with Xcode:

1. Navigate to the iOS project directory:
   ```bash
   cd "ios-app"
   npx cap open ios
   ```
   *Or open `ios-app/ios/App/App.xcodeproj` in Xcode.*
2. Connect your iPhone to the Mac.
3. In Xcode:
   - Select your iPhone as the build target in the top toolbar.
   - In **Signing & Capabilities**, select your personal Apple ID team (free Apple ID works).
   - Press **Cmd + R** (Run) to install and launch directly on your device.
